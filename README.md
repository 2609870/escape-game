# Luigi's escape

Projet conçu en équipe avec : Rémi, Federer

## Le public cible

- Pour qui : Famille
- Âge minimum : 7 ans
- Niveau d'expérience : Intermédiaire
- Ce qui est important pour eux : Se sentir intelligent, interagir entre eux, solutions alternatives "cachées"

## La conception

- Thème : Luigi's Mansion
- L'intrigue : Le professeur Karl Tastroff a engagé des gens pour chasser les fantôme du manoir dont il a récemment fait l'acquisition en les traquant de pièce en pièce.
- Temps : 1h15
- Le nombre d'énigmes : 7
- Le type d'énigmes : Déduction et observation
- Les besoins matériels : Tapis, lampes, lustre, meubles, fauteuils, faux livres, escaliers, portes
- Les besoins technologiques : Télévision, projecteurs, électricité, dispositifs de son, horloge, détecteurs, machine à fumée, projecteurs, mécanismes
- Les besoins humains : Construction, électricité, entretien
- Le plan des salles (croquis) :

![Plan des salles](plan-salles.jpg)

## Les éléments importants

- Engagement sensoriel : Vue, ouïe, toucher
- Conception spatiale : Les joueurs débloquent et découvrent différentes pièces d'un manoir à travers des énigmes.
- Rétroaction : Effets sonores quand on obtient une clé, aspire ou attrape un fantôme, fantôme projeté sur un mur quand on l'aspire,  aspirateur qui vibre légèrement quand on aspire un fantôme
- Technologie invisible : Sources de lumière placées stratégiquement de sorte à ce que la technologie qu'on ne doit pas voir reste cachée.

## Les risques et la sécurité

- Risque 1 : Quelqu'un se cogne (solution : Utiliser des meubles avec des coins arrondis)
- Risque 2 : Quelqu'un est aveuglé par la lumière (solution : Faire les flashs de lumière avec une lumière pas trop forte)
